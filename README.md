# AI Resume Analyzer & Skill Gap Recommendation System

An intelligent, AI-powered web application that helps students and job seekers analyze their resumes, evaluate ATS compatibility, identify missing skills, and improve their chances of getting shortlisted.

## 🚀 Features

- **Resume Upload:** Upload your resume for analysis.
- **ATS Score Analysis:** Evaluate your resume and generate an ATS score.
- **Skill Extraction:** Automatically identify technical and professional skills.
- **Job Description Matching:** Compare your resume with a given job description.
- **Skill Gap Analysis:** Identify missing skills required for a target job.
- **AI Feedback:** Get suggestions to improve your resume.

## ⚙️ Installation & Setup

### 1. Clone the Repository

```bash
git clone https://github.com/vanshika2126/AI-Resume-Analyzer.git
cd AI-Resume-Analyzer
```

### 2. Setup Frontend

```bash
cd frontend
npm install
npm run dev
```

### 3. Setup Backend

Open another terminal:

```bash
cd backend
python -m venv venv
```

Activate virtual environment on Windows:

```bash
venv\Scripts\activate
```

Install dependencies:

```bash
pip install -r requirements.txt
```

Run Flask:

```bash
python app.py
```
